# Hey, I'm Ash 👋

I'm a full-stack developer from West Yorkshire. Most days I'm working in Laravel and Vue, with some React Native when there's an app involved.

Before I got deep into code I spent a lot of time in product and testing, and it's stuck with me. I like building things that actually hold up once real people start clicking around.

At the moment I'm working on fintech and asset finance platforms. I also run **Shock Creative**, a small design and development studio, and I've got a habit of starting side projects. A few of them even get finished.

There's more about me over at [coded-4.co.uk](https://coded-4.co.uk).
